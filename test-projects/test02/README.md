# test02

Sample project for the Google Search AI mode harness (`google-search`): files are shared as text in the
prompt or as one uploaded text file, and checks run by name. Committed with the repo; its `.reiner/` folder (browser profile, state)
is ignored by the root `.gitignore`.

- `src/slug.js`, `src/words.js`: small functions to ask about and change.
- `tests/`: run with `npm test` (Node's own test runner, nothing to install).
- `reiner.cmd` (PowerShell) and `reiner` (bash) run the CLI from source with this folder as the project.
