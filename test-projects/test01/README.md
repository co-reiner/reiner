# test01

Sample project for running and live-testing Reiner. Committed with the repo; its `.reiner/` folder
(browser profile, state) is ignored by the root `.gitignore`.

- `src/greet.ts`, `src/util/math.ts`, `docs/notes.md`: the files `pnpm live:transfer` changes and resets.
- `reiner.cmd` (PowerShell) and `reiner` (bash) run the CLI from source with this folder as the project.
