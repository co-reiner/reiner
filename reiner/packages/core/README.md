# @co-reiner/core

Shared building blocks of [Reiner](https://github.com/co-reiner/reiner): the harness module contract,
project config, the tool protocol and the rules for sharing files and applying changes.

Install [`@co-reiner/reiner`](https://www.npmjs.com/package/@co-reiner/reiner) instead; it brings this package
with it. Setup, configuration, warnings and the licence are in its README.
