# @co-reiner/cli

The [Reiner](https://github.com/co-reiner/reiner) command line without any harness: the terminal UI, its
commands and file exchange. On its own it starts as `reiner-cli` and has nothing to drive.

Install [`@co-reiner/reiner`](https://www.npmjs.com/package/@co-reiner/reiner) instead; it brings this package
with its harnesses. Setup, configuration, warnings and the licence are in its README.
