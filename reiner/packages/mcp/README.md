# @co-reiner/mcp

The MCP client of [Reiner](https://github.com/co-reiner/reiner): it connects the MCP servers you configure
(Figma's desktop server, for example) and lets the model in your browser harness call their tools.

Install [`@co-reiner/reiner`](https://www.npmjs.com/package/@co-reiner/reiner) instead; it will bring this
package with it. Setup, configuration, warnings and the licence are in its README.
