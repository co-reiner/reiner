# @co-reiner/exchange-packs

File exchange by packs for [Reiner](https://github.com/co-reiner/reiner) harnesses that take uploads: the
project goes up as one pack, changes come back as a diff or a patch file.

Install [`@co-reiner/reiner`](https://www.npmjs.com/package/@co-reiner/reiner) instead; it brings this package
with it. Setup, configuration, warnings and the licence are in its README.
